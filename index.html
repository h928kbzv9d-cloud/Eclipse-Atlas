    Embedded reference dataset · v1.0

    Reference data, with limits

    The dataset stores selected future eclipse dates (solar and lunar), event class and type, broad visibility regions, path-reference lines for solar central eclipses, and a limited set of supported local circumstances. Lunar entries are reference-only and do not include exact local circumstances. This dataset is curated for planning discovery, not a substitute for an authoritative local prediction immediately before travel or observation.

    NASA Future Eclipses · NASA Eclipse Web Site
